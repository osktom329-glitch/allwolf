# オールウルフ

全員が人狼のバトルロイヤル。1台の端末を回して遊ぶ自動GM。ひとりでボットと対戦もできる。

## 置き方（GitHub Pages）

1. このフォルダのファイルをリポジトリの直下に置く
2. Settings → Pages → Build and deployment で「Deploy from a branch」、Branch を `main` / `(root)` にして Save
3. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

## スマホに入れる

- iPhone: Safari で開く → 共有 → ホーム画面に追加
- Android: Chrome で開く → メニュー → アプリをインストール（またはホーム画面に追加）

一度開けばオフラインでも遊べる。進行中のゲームは端末に保存され、途中で閉じても続きから再開できる。

## 更新するとき

`index.html` と `sw.js` を新しいものに置き換える。アプリは次に開いたとき（ネットにつながっていれば）新しい版になる。
